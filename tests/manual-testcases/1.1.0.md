# Manual Test Cases — 1.1.0

## HTTPRoute Status Ownership

### Kuadrant policies coexist with MCP-owned status parents

**Related PR**: Fix for [#1513](https://github.com/Kuadrant/mcp-gateway/issues/1513).

**Why manual**: The e2e CI environment does not install Kuadrant. This scenario
checks that its policy-controller preserves MCP-owned HTTPRoute status while
removing its own entry. Registration deletion and status schema validation are
covered by controller integration tests.

- [ ] Set up the local environment from the branch being tested:

  ```bash
  make local-env-setup && make auth-example-setup
  ```

- [ ] Wait for `test-server1` to be Ready and confirm `mcp-server1-route` has
  entries owned by both `kuadrant.io/policy-controller` and
  `mcp.kuadrant.io/mcp-gateway`. Save MCP's complete entries for comparison:

  ```bash
  kubectl wait -n mcp-test --for=condition=Ready mcpsr/test-server1 --timeout=180s
  kubectl get httproute mcp-server1-route -n mcp-test -o json |
    jq -e '.status.parents[] | select(.controllerName == "kuadrant.io/policy-controller")'
  MCP_STATUS_DIR=$(mktemp -d)
  kubectl get httproute mcp-server1-route -n mcp-test -o json |
    jq -S '[.status.parents[] | select(.controllerName == "mcp.kuadrant.io/mcp-gateway")]' \
    > "$MCP_STATUS_DIR/before.json"
  jq -e 'length > 0 and all(.[]; any(.conditions[]; .type == "Programmed" and .status == "True"))' \
    "$MCP_STATUS_DIR/before.json"
  ```

- [ ] Remove the two AuthPolicies and the TLSPolicy:

  ```bash
  kubectl delete authpolicy mcp-auth-policy mcps-auth-policy -n gateway-system
  kubectl delete tlspolicy mcp-gateway-tls -n gateway-system
  ```

- [ ] Wait until Kuadrant's entry disappears completely, then confirm MCP's
  entries are byte-identical to the saved entries. Repeat the first command
  until it succeeds:

  ```bash
  kubectl get httproute mcp-server1-route -n mcp-test -o json |
    jq -e 'all(.status.parents[]; .controllerName != "kuadrant.io/policy-controller")'
  kubectl get httproute mcp-server1-route -n mcp-test -o json |
    jq -S '[.status.parents[] | select(.controllerName == "mcp.kuadrant.io/mcp-gateway")]' \
    > "$MCP_STATUS_DIR/after.json"
  cmp "$MCP_STATUS_DIR/before.json" "$MCP_STATUS_DIR/after.json"
  ```

- [ ] Restore the example policies:

  ```bash
  kubectl apply -f config/keycloak/certificate.yaml
  kubectl apply -k config/samples/oauth-token-exchange/
  ```
